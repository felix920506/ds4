DeepSeek V4 Flash Vision Exp (IQ2XXS/Q2K), Strix Halo gfx1151, 128 GB, ds4 @ 1a746ff in Docker (ROCm). One session allocated for 1,048,576 tokens, filled in doubling steps. KV in use is the session snapshot size at each point; the ~1M value is extrapolated from that linear growth (no snapshot is taken at the last point). Physically, a 1M session holds ≈108 GiB from the first token (93.7 GiB GPU buffers + 13.8 GiB demand-paged KV that the engine touches up front), so the dashed line barely moves.
